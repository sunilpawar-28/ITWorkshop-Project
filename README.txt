# Intelligent Network Traffic Analysis System

## Files
- `Intelligent_Network_Traffic_Analysis.ipynb`: main project notebook
- `data/network_traffic.csv`: synthetic demo dataset
- `Project_Proposal.txt`: proposal text
- `requirements.txt`: Python dependencies
- `outputs/`: created when the notebook is run

## Run
1. Install Python and Jupyter Notebook.
2. Extract this project ZIP.
3. Open a terminal in the extracted `network_traffic_project` folder.
4. Run `pip install -r requirements.txt`.
5. Run `jupyter notebook`.
6. Open `Intelligent_Network_Traffic_Analysis.ipynb`.
7. Choose Kernel -> Restart & Run All (menu wording may vary).

The notebook expects to be run from the project folder. The dataset is synthetic, not live-captured traffic.

## Important
Do not capture or inspect traffic on networks or devices without authorization. This project analyzes supplied records and does not perform intrusive scanning.
